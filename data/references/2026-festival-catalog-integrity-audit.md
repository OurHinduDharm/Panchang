## Confirmed integrity defects

1. June status mismatch on main: the month file said approved while all 17 event records said needs-review. This PR aligns the month-level status to needs-review; the underlying dates remain unverified.
2. September status mismatch on main: the month file said approved while one event remained needs-review. This PR aligns the month-level status to needs-review; the event still requires review.
3. January duplicate presentation candidate: 23 January has both वसंत पंचमी and वसन्त पंचमी / सरस्वती पूजन. Both are marked approved and refer to the same observance. Consolidate or model as one event with multiple article links only after confirming the canonical description and links.
4. April duplicate presentation candidates: 2 April has three Hanuman Jayanti entries; 19 April has multiple Parashurama Jayanti/Akshaya Tritiya entries; 25 April has two Sita Navami entries. These are candidate duplicates, not instructions to delete; preserve distinct article links and meaningful regional naming.
5. July duplicate presentation candidates: 16 July has three Jagannath Ratha Yatra / Sankranti-related titles. Verify whether these are separate observances or duplicate aliases before consolidation.
6. August duplicate presentation candidates: 17 August has two Nag Panchami entries; 28 August has three Raksha Bandhan entries. These require one canonical visitor-facing card with alternate names/links if the underlying observance is the same.
7. March 2026 Holika Dahan / Holi / lunar eclipse cluster remains unresolved. Do not promote or alter dates from this audit; a location-specific tithi/Bhadra/eclipse review is required.

## Coverage gaps to verify, not yet confirmed omissions

The static catalog does not show a uniform monthly series for every common vrata family. Before adding any recurring event, compare with the live daily Panchang and current widget output to avoid duplicate display. Candidate families for a month-by-month coverage matrix:

- Ekadashi and Smarta/Vaishnava or Mahadvadashi distinctions;
- Pradosh, Masik Shivaratri, Sankashti and Vinayaka Chaturthi;
- Masik Durgashtami, Skanda Shashthi and Kalashtami;
- Purnima, Amavasya and Sankranti;
- regional observances, Jayantis and multi-day festival periods.

Absence from a static month file alone does not prove absence from the website: some observances may already be generated by the daily Panchang. Reconcile both display paths before changing the public catalog.

## Automation added

scripts/audit-festival-catalog.mjs checks month identity, date validity, chronology, end-date validity, event status vocabulary, month/event approval consistency, missing tithi metadata for tithi-based entries, duplicate normalized date/title pairs, and descriptions that promise a muhurta/time without a linked rule.

Tests are in tests/festival-catalog-integrity.test.mjs. Warnings are review prompts, not automatic date corrections. A missing muhurtaRule is not automatically an error: many observances do not need a displayed clock-time muhurta.

## Safety boundary

This audit does not modify public month JSON, festival dates, descriptions, or Blogger rendering. It does not change Udaya/Asta calculations. Disputed and alias records remain untouched until source/rule verification is complete.
