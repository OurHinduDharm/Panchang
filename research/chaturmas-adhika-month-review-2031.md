# Intercalary-month Chaturmas review — 28 November 2026

The calculated 2031 Pithoragarh candidate is July 1–November 24, with
completion November 25. Phase boundaries: July 31, September 28,
October 27. The July 31–September 28 dahi phase spans 59 civil days
because the current algorithm selects only nija lunar months.
These are calculation candidates, not an approved dietary decision.

## Sources inspected

- Nirnayasindhu, second pariccheda, Chaturmasya vrata:
  https://vishvasa.github.io/kalpAntaram/dharmaH/nibandhaH/kamalAkarabhaTTaH/nirNayasindhuH/
  permits Ashadha Shukla Ekadashi, Dwadashi or Purnima as commencement
  and specifies Kartika Shukla Dwadashi as completion. It discusses
  first versus subsequent commencement in the context of impurity
  and a quoted intercalary-month prohibition.
- Nirnayasindhu Chaturmasya section, Sanskrit and Marathi:
  https://www.transliteral.org/pages/z130528050726/view
  cites Bhavishya and Skanda traditions for the four dietary restrictions.
- Padma Purana, Uttara Khanda 64.10–12:
  https://sa.wikisource.org/wiki/पद्मपुराणम्/खण्डः_६_(उत्तरखण्डः)/अध्यायः_०६४
  addresses Vishnu's sleep/waking when an intercalary month intervenes;
  it does not by itself settle the extra dietary phase.
- Dharmasindhu, Malamasa discussion:
  https://whm.cdsharma.in/dharma-nirnay?g=ds&p=1&t=path
  gives a two-month continuation example for an existing Vaishakha
  bathing vow, not a direct proof for the four Chaturmas dietary stages.
