# Vaishakha Shukla Tritiya: separate observance evidence
Issue #546; follow-up to #548. Review-only, not a date correction to published cards.

* Nirnayasindhu, second pariccheda, Vaishakha Yugadi section: https://vishvasa.github.io/kalpAntaram/dharmaH/nibandhaH/kamalAkarabhaTTaH/nirNayasindhuH/ (search पूर्वाह्णस्तत्र and परशुरामजयन्तीनिर्णयः). Defines Purvahna as half daylight, chooses later when both days have Purvahna coverage, and treats Parashurama separately by Pradosha.
* Dharmasindhu, second pariccheda, Vaishakha: https://whm.cdsharma.in/dharma-nirnay?g=ds&p=9&t=path; Marathi translation https://www.transliteral.org/pages/z80422071006/view. Distinguishes greater/less than six ghatis of later-day Purvahna coverage. Equal boundary and scope across ritual categories need review. Code exposes fixed 24-minute ghati and seasonal daytime muhurta diagnostic separately, does not approve either disputed interpretation.
* Dharmasindhu Parashurama passage explicitly refers to first night yama for date and Pradosha for arghya/puja: https://www.transliteral.org/pages/z80422071133/view. Existing resolver uses three fifteenths of night; a quarter-night versus that convention should be audited before publication. No change to existing rule in this PR.
* Drik New Delhi lists the four components together on 5 May 2030: https://www.drikpanchang.com/panchang/day-panchang.html?date=05%2F05%2F2030&lang=en . External date cross-check only, not the input for Pithoragarh calculation.

The annual review artifact now contains a separate component audit for both target years. It retains original card and aggregate mapping counts. Akshaya only produces a candidate if the explicit diagnostic source variants agree and local intervals are continuous and complete. Parashurama uses existing candidate resolver; Yugadi naming/ritual (#545) and Matangi ritual rule stay manual review. No automatic approval, no production content or UI change. No date is selected from a copied Gregorian reference.
