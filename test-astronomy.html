6. Heliacal Udaya / Asta Validation

This section uses Swiss Ephemeris heliacal visibility calculation. The API searches forward from the supplied start date and returns the next heliacal phenomenon; it does not target the reference date. 9. Sūrya-siddhānta Ch.9 — Lagnāntara-asu Diagnostic

Independent diagnostic of the classical lagnāntara-prāṇa method. This remains separate from the existing elongation and Swiss heliacal tests.

Research status: Validation only. C is selected from Sūrya-siddhānta IX.6–9, not from TKS. The diagnostic uses a stated fixed ayanāṃśa benchmark and computes Aksha dṛkkarma with the planet's own hour-angle/half-day ratio. This is still a research implementation, not production Panchang logic.

8. Diagnostic Notes

  • Elongation = angular separation between Sun and planet.
  • Altitude = actual local horizon position of the object.
  • Sun altitude indicates twilight/daylight geometry.
  • ARCV = apparent/geometric vertical separation relevant to heliacal visibility.
  • Magnitude is important because visibility is not determined by elongation alone.
