🧪 PR Browser Preview

OurHinduDharm Panchang के Draft या खुले Pull Request को main में merge किए बिना अलग Preview में खोलने का सहायक पेज।

यह पेज PR की जानकारी और बदली हुई फ़ाइलें GitHub API से पढ़ता है। Preview सेवा पर उपलब्धता अलग से निर्भर करती है।

Preview में क्या जाँचें?

  • पेज बिना JavaScript या module errors के खुलता है।
  • बदले हुए फ़ीचर के साथ तारीख, स्थान और सामान्य उपयोग के मामले जाँचें।
  • मोबाइल और डेस्कटॉप लेआउट देखें।
  • Mini Panchang और अन्य मौजूदा सुविधाएँ पहले की तरह काम कर रही हैं।
  • ब्राउज़र DevTools Console में लाल errors देखें।
सुरक्षा और सीमाएँ: Preview में PR का JavaScript चलेगा। केवल भरोसेमंद PR खोलें। यह सुविधा अलग third-party Preview host का उपयोग करती है; अगर वहाँ Preview उपलब्ध न हो, तो GitHub branch/commit से स्थानीय server पर चलाना होगा। पेज खुल जाना अपने-आप में सही गणना या पूर्ण परीक्षण का प्रमाण नहीं है।

यह परीक्षण उपकरण मुख्य Panchang की गणना या फ़ाइलों को नहीं बदलता।
