PR Review Helper

यह पेज OurHinduDharm Panchang के Draft या खुले Pull Request की जानकारी देखने और मैन्युअल टेस्ट की योजना बनाने के लिए है। PR को main में merge करने की ज़रूरत नहीं है।

सुरक्षा डिज़ाइन: यह टूल PR का HTML/JavaScript चलाता ही नहीं है। यह केवल GitHub API से PR का विवरण और बदली हुई फ़ाइलों के नाम/आँकड़े पढ़ता है। कोई third-party live-preview host इस्तेमाल नहीं होता।

मैन्युअल ब्राउज़र टेस्ट

  1. PR की Files changed टैब में हर बदलाव पढ़ें।
  2. GitHub पर भरोसेमंद कोड की समीक्षा के बाद ही उसे अपने स्थानीय टेस्ट वातावरण में चलाएँ।
  3. ब्राउज़र Console में errors देखें और सामान्य तथा सीमा-स्थितियों की जाँच करें।
  4. Mini Panchang और अन्य पहले से सही सुविधाओं की regression जाँच करें।
  5. जाँच पूरी होने तक Draft PR को merge न करें।
ध्यान दें: GitHub PR का विवरण दिखना, कोड की सुरक्षा या गणना की शुद्धता का प्रमाण नहीं है। यह पेज कोड execute नहीं करता और browser preview नहीं देता। PR को चलाना हो तो केवल समीक्षा किए गए कोड को अलग/local test environment में चलाएँ।

यह पेज Panchang की calculation files में बदलाव नहीं करता। यह GitHub API तक अनुरोध भेजता है; GitHub API अनुपलब्ध या rate-limited हो तो जानकारी नहीं दिख पाएगी।
